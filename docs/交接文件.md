## 1. 這是什麼

**Shioaji Pro — 台股專業交易終端**。以永豐 [Shioaji](https://sinotrade.github.io/)
的 HTTP API + SSE 串流打造，涵蓋 TWSE／TPEX／TAIFEX。

- **前端全開源、零後端程式**：UI、行情串流、下單鏈路都在這個 repo，clone 下來就能 build 出 Web 版終端。
- 直接對接使用者本機跑的 `shioaji server`（sidecar），app 本身不含後端。
- 桌面版外殼（Tauri）、**AI Agent、策略回測**是**專屬閉源模組**，不在本 repo（見第 3 節 `@modules`）。
- 授權：AGPL-3.0。

這個 fork（`how0531/shiaoji-pro-vedio`）額外含一個 **教學影片專案**（`video/`），與 app 原始碼分家並存。

## 3. 架構重點

### Web 版 vs 桌面版（Tauri）
- `vite.config.ts` 用 `@modules` alias：桌面 build 會 checkout 私有模組到 `./modules/index.ts`；
  開源 build 找不到就 fallback 到 **`src/modules-stub/index.ts`**（空殼）。**AI Agent／付費分級功能就住在這個私有模組裡。**（已讀 vite.config.ts）
- `lib/tauri.ts` 匯出 `isTauri` 旗標與桌面 API 封裝；很多桌面 API 有瀏覽器 fallback，所以 Web 版能跑。（推斷，僅讀過匯入）

### 開機流程（`src/main.tsx`，已讀）
`import './lib/polyfills'`（**必須第一個 import**，補 `structuredClone`、`AbortSignal.timeout` 等）
→ `initTheme()` → `startAnalytics()` → `startTriggerEngine()` → `bootstrap()` →
`AppGate`：
- **Web** → 直接 render `<App />`（不卡 onboarding）
- **桌面** → 若沒存 API key/secret，顯示 `OnboardingSetup` 全螢幕設定頁

### 資料流（推斷 + 部分已讀）
- **行情**：單一 **SSE** 連線串流 tick／五檔（`lib/stream.ts`）。`onAnyTick`、`onOrderEvent`、
  `getStreamStatus()`（`'live'` 才允許下單）、`getAliasFor()`（連續契約代號對應）。
- **下單**：`lib/shioaji.ts`（`placeStockOrder`／`placeFuturesOrder`／`cancelOrder`／`fetchTrades`）；
  上層封裝在 `lib/trade.ts`。
- **dev 代理**（`vite.config.ts`）：`/api` → sidecar `127.0.0.1:21322`（可用 `VITE_API_TARGET` 蓋）；
  `/news/*` → 各新聞站（補 Origin/Referer 繞 CORS）。
- **版本握手**：根目錄 `SHIOAJI_VERSION` 於 build 時注入，開機比對 sidecar 版本。

## 5. 關鍵模組（交易相關，已讀）

### `lib/trade.ts`
- `placeQuickOrder(contract, action, price, quantity, opts?)`：一發式下單。`price === null` = 市價。
- **安全機制**：`assertTradingLive()` — 行情非 `live` 直接擋單（避免連線斷掉時誤以為送出）；
  `checkOrderAllowed()` 風控／kill switch（可用 `opts.bypassRisk` 繞過，僅保護性出場用）。
- 通知中心：`notify()` / `logNotice()` / `subscribeNoticeLog()`。
- 股票是「股數」的出場拆整張＋零股：`placeStockExitByShares()`。

### `lib/trigger-engine.ts` — 客戶端觸價引擎（**重要**）
- 監看 SSE tick，條件成立就送**市價單**並自我移除；支援 **OCO 群組**。
- `TriggerOrder.kind`：`stop`｜`take`｜`alert`｜**`trail`**（本次新增）。
- 持久化到 **localStorage**，但**只在 app 開著時運作**（純前端引擎）。
- **移動停損（trail）**：逐 tick 追蹤峰值，`峰值 × (1∓ trailPct%)` 為停損價，回撤觸價出場。
  峰值存記憶體不持久化（重開以當下價重新起算）。核心數學抽在 **`lib/trail.ts`**（純函數，可 node 驗）。

### `components/flash-order.tsx` — 閃電下單（DOM 價格梯）
- tick-space 固定視窗價格梯，自動跟隨現價（滑鼠移入時暫停，避免點到移動中的價位）。
- **安全開關（armed）**：預設鎖定，行情斷線自動解除 armed，Esc 解除。
- 金額鈕（50/100/250/500 萬）依契約名目價值換算張數／口數。
- **本次新增**：`自動拆單`（量超過每筆上限就拆多筆各 ≤ 上限，同時送）、
  `移動停損 _%`（開/加倉成交後掛反向 trail，純平倉不掛）。

### 新聞（本次相關）
- `lib/news.ts` 抓新聞、`lib/news-digest.ts` 彙整今日焦點、
  `lib/news-sentiment.ts` 規則層**利多/利空分類器**（詞庫＋反轉語＋否定翻轉＋轉折加權，
  移植自 stock-news-skill，`scripts/check-news-sentiment.ts` 對 Python 版 37/37 一致）。
- `components/news-digest.tsx`「自製-今日焦點」：每股多/空則數＋逐則情緒標籤，整列**背景熱度條**（底色深淺＝新聞熱度）。

### 其他（推斷，僅由檔名／README）
`bracket.ts`（括號單）、`risk.ts`（風控）、`privacy.ts`（金額遮蔽）、`indicators.ts`／`ta.ts`／
`custom-indicators.ts`／`custom-worker.ts`（技術指標，含 Web Worker 跑自訂指標）、
`contracts-cache.ts`、`sector-sync.ts`／`stock-index.ts`、`option-pick.ts`／`order-report.ts`。

## 6. 程式慣例

- **只用 named export**（無 default export）。
- 樣式一律 vanilla-extract `*.css.ts`，用 `theme.css.ts` 的 `vars.*` token，不寫死顏色。
- 中文註解解釋「為什麼」（領域理由、踩過的坑、issue 編號），照抄這風格。
- **交易路徑安全至上**：`assertTradingLive`、kill switch、armed 開關、inflight 去重（防連點）。改動下單鏈路務必保留這些護欄。
- 非平凡邏輯（尤其金錢/安全路徑）留一支可跑的自測：見 `scripts/check-*.ts`（`node scripts/check-xxx.ts`）。

## 7. 開發者實戰須知（本次 session 踩過，務必看）

1. **`pnpm dev` 會失敗**：pnpm 跑腳本前的依賴檢查會重跑 install，遇到 esbuild 的 build script
   被 `ERR_PNPM_IGNORED_BUILDS` 擋下而 exit 1，還沒進 vite 就中止。
   - 解法 A（永久）：`pnpm approve-builds` 勾選 esbuild。
   - 解法 B（繞過）：直接跑 vite → `node node_modules/vite/bin/vite.js`（`PORT=5173` 可指定埠）。
   - esbuild 功能其實正常（原生執行檔在 `.pnpm/@esbuild+win32-x64/`），這只是 pnpm 的預檢在擋。
2. **一定要用 pnpm 佈局的 `node_modules`**：若被 npm 裝過（扁平佈局），會缺 `@tauri-apps/plugin-fs` 等 → 白畫面。
   修法：`rm -rf node_modules && pnpm install --frozen-lockfile`。
3. **真實資料要 Shioaji sidecar** 跑在 `127.0.0.1:21322`。沒開的話 UI 版面會渲染，但行情/下單面板無資料。
   → **實際送單/觸發無法只靠 dev server 驗證**，需 sidecar + 登入。
4. **本地 repo 目前是 shallow**：`video/` 有大量影片大檔，`git fetch --unshallow` 會逾時。
   要完整歷史再掛著慢慢跑；日常開發不影響。
5. **`core.autocrlf=true`**：診斷 diff 別加 `-c core.autocrlf=false`（會把 CRLF 差異放大成整檔變更假象）。
   直接 `git diff` 看正規化後的真實 diff。
6. **Node v24 可直接跑 `.ts`**（type-stripping），所以 `scripts/check-*.ts` 用 `node` 直接跑。
7. `package-lock.json`（npm 產物）是殘留，pnpm 專案不需要，別提交。
